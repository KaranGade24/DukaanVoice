# Categories

[Inventory overview](README.md) · [All tab guides](../README.md)

## Why categories matter

Categories group products and let you filter the Inventory list. Each product must belong to an active category in the same shop.

The backend creates common starter categories for a shop, such as Grocery, Dairy, Beverages, Snacks, Personal Care, Household, Electronics, Clothing, and Other. You can add categories that fit your business.

## Add and edit a category

1. From Inventory, tap **Categories**.
2. Tap **Add category** to create one, or tap the edit icon beside an existing category.
3. Enter a name. Description, icon, and image URL are optional.
4. Tap **Save category**.

You can also create a category by name while adding a product. Use the Categories screen when you want to add its description, icon, or image.

## Search, filter, and deactivate

- Use the search box to find a category by name.
- Each row shows the count of active products assigned to the category.
- Tap a category name to open Inventory filtered to that category.
- Use the eye control to deactivate an active category or reactivate an inactive one. Inactive categories cannot be selected for new products, but the category record and its product history remain.

## Delete carefully

The app asks for confirmation before deleting. The backend rejects deletion while products are assigned to that category. Reassign or archive those products first, or deactivate the category if you only need to stop using it. Deletion is permanent for that category record.

## If the save fails

Category names are required and limited to 80 characters. A duplicate name or a category that does not belong to your shop can be rejected by the server. Use the displayed message to resolve the issue; do not assume a failed save created the category.
